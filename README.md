# C盘清理工具 CleanC

Windows 图形界面的 **C 盘清理与磁盘治理工具**：清理垃圾、找出空间被谁占了、卸载软件、必要时重新划分磁盘。

C# / .NET 8 + WinForms，**无第三方依赖**，纯离线运行。默认以**普通权限**启动，只在真正需要管理员时才申请提权。

## 能做什么

| 你想解决的问题 | 用哪个功能 |
|---|---|
| C 盘红了，清掉临时文件和缓存 | 主界面清理 |
| 开发机上 `node_modules`、虚拟环境、构建产物堆满了 | 开发者环境 |
| 卸载软件，顺带清掉残留 | 软件卸载 |
| "空间到底被谁占了？" | 占用分析（**只读**） |
| C 盘不够用，想把 D 盘空间挪过来 | 磁盘分区 |

**几个让人放心的前提：**

- 双击就能用，不会一上来弹 UAC
- **先分析、后清理**：必须先在列表里看到每项能释放多少，再确认
- 删除前逐项过安全闸门，盘根 / Windows / `Program Files` / 用户配置目录一律拒绝删除
- 纯本地运行，不联网、不上传

## 克隆与运行

```powershell
git clone https://github.com/natasapaul781-tech/haflower.git
cd haflower
```

> 主程序在 **`main\` 子目录**里，不在仓库根目录。
> 不想用命令行？仓库页面点 `Code` → `Download ZIP` 也一样。

### 编译成免安装单文件版（推荐）

自带 .NET 运行时，拷到任何 Windows 电脑都能直接双击运行：

```powershell
dotnet publish main\src\CleanC\CleanC.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o dist
```

产物：`dist\CleanC.exe`（约 157 MB）。建议把它单独放一个固定文件夹，例如 `D:\Tools\CleanC\`。

> ARM64 电脑把 `-r win-x64` 换成 `-r win-arm64`。首次 publish 需联网下载运行时包（约 150 MB）。

### 或者直接运行

```powershell
dotnet run --project main\src\CleanC\CleanC.csproj -c Release
```

也可以双击 `main\CleanC.sln` 用 Visual Studio 打开后按 F5。

## 五分钟上手

1. **启动程序**——会先弹捐赠海报，按任意键关闭。
2. **看列表**——程序已按推荐值预勾选好安全项目；有风险的项目（如 `NuGet 全局包`）默认**不勾选**。
3. **点「分析」**——等进度条走完，`预估大小` 列填上真实数字。**这一步不删除任何东西。**
4. **检查列表**——`预估大小` 是否符合预期；**双击任意一行**能把它的位置复制到剪贴板，粘到资源管理器就能看看到底是什么。
5. **点「清理选中项」**——弹确认框告诉你"将清理 N 项，预计释放约 X"，确认后开始。

清理过程中窗口会被遮罩盖住，防止误点；可以点 **「取消」** 中断（已完成的部分保留）。被占用或无权限的文件会**自动跳过**并记入日志，不会卡住。完成后程序自动重新分析，刷新剩余大小。

> ✅ 只想看看能清多少、暂时不想删：做到第 3 步就够了，`分析` 是纯只读操作。

### 关于权限

程序默认普通权限运行。勾选了系统级清理项或点「磁盘分区」时，会问你要不要提权：

- **「是」** → 弹 UAC 提权重启（会带上你的用户配置目录，保证清理的仍是**你自己**的缓存）
- **「否」** → 跳过需要管理员的项，继续清理其它
- **「取消」** → 什么都不做

标准账户、没有管理员凭据也能用——大部分功能本来就不需要管理员。

## 六个功能

主界面右上角五个按钮 + 主界面本身就是清理功能。

### 主界面清理

清临时文件、npm/pnpm/pip/NuGet 缓存、缩略图缓存、错误报告、浏览器缓存、微信/钉钉/Steam 缓存、回收站等。默认勾选的都是安全的；第三方缓存只清"名字就叫缓存"的标准子目录，**不动聊天记录、书签、密码、下载文件、游戏存档**。

### 开发者环境

扫描并清理 `node_modules`、Python 虚拟环境、Conda 环境、`target`、`build`、Maven/Gradle 缓存、AI 模型缓存、IDE 缓存等。

- 扫描范围可选：**用户目录 + 常用位置** / **整个系统盘** / **所有固定磁盘**
- 默认勾选「按占用排序」，一眼看出哪个最占地盘
- **双击某行**看详情：大小明细、文件数、库清单
- 工具链本体（.NET SDK、Android SDK…）和 WSL/Docker 虚拟磁盘标记为「仅统计」——**只展示占用，不提供删除**

### 软件卸载

列出已安装软件，显示**实测占用**与安装/数据位置，两个标签页：

- **常规软件卸载**：MSI / 有官方卸载程序的软件，可选静默或运行官方卸载程序
- **深度软件卸载**：商店(UWP)应用 / 无官方卸载程序的软件，首次进入有风险提示，**「全选」被禁用**防止批量误操作

卸载后会**轮询复验**注册表条目是否真的消失（成功 / 需重启 / 未完成 / 失败）。没清干净的会进入**残留清理**，列出确定性匹配的目录、注册表项、快捷方式——**默认全部不勾选**，逐项核对后手动勾。

> 卸载执行期间不能取消也不能关窗口：中途强杀卸载程序会让软件在注册表和磁盘上状态不一致。

### 占用分析（只读）

按大小排名目录，双击逐层下钻，回答"空间到底在哪"。

- 选根路径（各固定磁盘，或任选目录）+ 深度（2/3/4/5，默认 4）
- 面包屑导航：`上一级` / `回到根`；已达深度上限的目录双击可就地展开
- 可 `复制路径`、`导出 CSV`
- **刻意没有删除按钮**——它面对的是任意目录（包括你的工程目录），风险大于便利。知道要删什么之后，去对应功能里删

口径：不跟随 junction/符号链接，无权限目录跳过并计数，隐藏/系统文件计入，硬链接与去重存储按逻辑大小统计。

### 磁盘分区

分盘 / 合盘 / 用未分配空间新建分区。**打开时只做只读检测。**

- **默认交付物是《操作说明书》**（导出到桌面），你可以照着自己动手，不必让工具执行
- 推荐值按**本机实测**计算，不写死数字
- **合盘不替用户备份**：先只读盘点源分区（真实文件数与主要目录），风险确认窗的**销毁按钮默认禁用**、**默认按钮是「取消（我要先备份）」**，勾选确认后再要最后一次确认
- 删除前强制拦下：源分区是系统盘 / 有页面文件 / 正放着本程序
- 想让工具执行，必须同时勾选「风险确认」和「我已阅读说明书，确认由本工具执行」
- **执行期间是危险档**：不给取消按钮，关窗口被拒绝

> ⚠️ 合盘删除分区**不可撤销**。删除后文件将无法访问，比格式化更彻底。**请在工具之外自行备份。**

### 操作日志

所有破坏性操作自动带时间戳写入**程序所在目录**的 `operations.log`（程序目录不可写时自动退到 `%LOCALAPPDATA%\CleanC\`）。主界面点「操作日志」可查看、导出副本、清空。超过 2 MB 自动轮转，纯本地、不联网。

## 安全吗

| 机制 | 说明 |
|---|---|
| 先分析后清理 | 删除前必须看到预估大小并确认 |
| 安全闸门 | 所有递归删除在**列出时**和**动手前**各校验一次，命中即拒绝并写明原因 |
| 拒绝删除的位置 | 盘根与共享根、`Windows`（仅放行 `Temp` 与 `SoftwareDistribution\Download`）、`Program Files`/`ProgramData`/`Users` 本体、任意用户的配置目录、程序自身目录 |
| 符号链接拒绝 | 统计与删除都不跟随 junction / 符号链接 |
| 占用文件跳过 | 逐文件删除，锁定或无权限的记录后跳过，不中断整体 |
| 签名复验 | 删除时重新确认目录仍是当初检测到的产物（如 `node_modules` 仍含 `package.json`） |
| 仅统计项不可删 | 工具链本体、WSL/Docker 虚拟磁盘：UI 与删除引擎双重拦截 |
| 统计只读 | 占用分析、软件占用实测、开发者环境大小全部只读 |

**不碰**：下载、桌面、文档等个人文件；聊天记录、书签密码、游戏存档。

**不做**：Prefetch、WinSxS、系统还原点、休眠文件（建议用系统「磁盘清理」或 DISM）；不做全注册表关键字扫描；不替用户备份。

## 常见问题

<details>
<summary><b>双击没反应 / 提示缺少 .NET？</b></summary>

运行的是框架依赖版（约 141 KB）。装 [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)，或改用上面的 `dotnet publish` 编译自带运行时的单文件版。

</details>

<details>
<summary><b>为什么有些清理项没出现？</b></summary>

目标目录不存在就不会列出（没装 Chrome 就没有 Chrome 缓存项）；命中安全闸门的项会被剔除。想看原因，去操作日志搜「已跳过」。

</details>

<details>
<summary><b>日志文件在哪？</b></summary>

程序自己所在目录（`CleanC.exe` 旁边）的 `operations.log`。程序目录不可写时退到 `%LOCALAPPDATA%\CleanC\operations.log`。「操作日志」窗口顶部会显示实际路径。

</details>

<details>
<summary><b>清理时会删错东西吗？</b></summary>

删除前有两道确认，且每个目标在列出时和删除前各过一次安全闸门。被占用或没权限的文件自动跳过。如果你担心，先只点「分析」——那是纯只读的。

</details>

<details>
<summary><b>编译报 NETSDK1045 / 找不到 net8.0-windows？</b></summary>

没装 .NET **8** SDK（可能只装了更高版本）。本项目目标框架固定 `net8.0-windows`，用 `dotnet --list-sdks` 确认有 `8.` 开头的版本。

</details>

<details>
<summary><b>企业电脑、标准账户能用吗？</b></summary>

可以。大部分功能不需要管理员（临时文件、开发缓存、浏览器缓存、占用分析、软件列表、操作日志）。系统级清理和磁盘分区用不了时会提示，选「否」跳过即可。

</details>
